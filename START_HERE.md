## ✅ Complete Command Reference

### Automation Path 1: CSV → Auto-Generate
```bash
# Step 1: Prepare CSV
data/testcases.csv

# Step 2: Parse
python parser/demo.py
# Output: data/parsed_testcases.json

# Step 3: Plan
python planner/demo.py
# Output: data/planned_testcases.json

# Step 4: Generate Framework
python generator/demo.py
# Output: object_repo/, pages/, steps/, tests/, conftest.py

# Step 5: Validate Quality
python validator/demo.py
# Output: validation_report.json

# Step 6: Run Tests
pytest tests/ -v
# Output: Test results ✅
```

### Automation Path 2: Workflow → Extract Locators
```bash
# Step 1: Create workflow JSON
workflows/your_test.json

# Step 2: Extract locators
python tools/intelligent_locator_extractor.py workflows/your_test.json
# Output: data/snapshots/YYYYMMDD_locators.json

# Step 3: Write test script
tests/test_your_name.py

# Step 4: Run test
pytest tests/test_your_name.py -v
# Output: Test results ✅
```
